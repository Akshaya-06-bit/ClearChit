# ClearChit

A backend system for transparent and auditable chit fund management.

## Objective

ClearChit aims to digitize the management of chit funds while providing transparent contribution tracking, bidding, payouts, dividends, and an immutable audit ledger.

## Core Features

- Chit group management
- Member management
- Monthly contribution tracking
- Sealed bidding
- Payout processing
- Dividend calculation
- Immutable audit ledger
- Scheduled monthly activities
- Authentication and authorization
- Reporting and transparency

## Tech Stack

- Java
- Spring Boot
- PostgreSQL
- Redis
